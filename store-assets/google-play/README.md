# Flowe — Google Play store assets

Generated by `node scripts/generate-icons.mjs` from `assets/brand/flowe-logo.svg` and
`assets/brand/flowe-mark.svg`. Don't edit the PNGs by hand: change the SVG and re-run the script.

| File | Size | Format | Where to upload in Play Console |
|---|---|---|---|
| `icon-512.png` | 512 × 512 | 32-bit PNG (RGBA), ≤ 1 MB, full-bleed square, no pre-rounded corners or shadow (Play applies its own mask) | **Grow users → Store presence → Main store listing → Graphics → App icon** |
| `feature-graphic-1024x500.png` | 1024 × 500 | 24-bit PNG, no alpha, ≤ 15 MB | **Main store listing → Graphics → Feature graphic** |
| `icon-1024.png` | 1024 × 1024 | 32-bit PNG (RGBA), rounded master (r 228) | Not uploaded to Play. Master export for press kits, the website and other stores |

Brand values: background gradient `#011A4D` (top) → `#1665B1` (bottom), white `#FFFFFF` mark with a
6.5-unit stroke in a 64-unit box, drawn at 600/1024 of the icon edge.

Phone screenshots (at least 2, required for publishing) aren't generated here. Capture them from a
device build and upload them under **Main store listing → Graphics → Phone screenshots**.
